# Chrome Web Store 发布指南

> 本文档是 ClipFlow 上架 Chrome Web Store 的操作手册与现成素材。每次发版只需：升版本号 → `npm run build` → `npm run zip` → 上传新 zip。

## 1. 前置条件

- [Chrome Web Store 开发者控制台](https://chromewebstore.google.com/devconsole) 注册（一次性 $5）
- 素材清单：
  - 包体：`npm run build && npm run zip` 产出的 `clipflow-vX.Y.Z.zip`（manifest 位于压缩包根目录）
  - 商店图标：`dist/icons/icon128.png`（128×128）
  - 截图 1–5 张：1280×800 或 640×400（建议：剪藏列表 / 工作台 / 自动采集规则编辑器 / 设置页）
  - 隐私政策 URL：指向本仓库 README 的 [隐私政策](../README.md#隐私政策) 章节

## 2. 商店文案（可直接粘贴）

### 名称

```
ClipFlow - 跨网页复制收集器
```

### 简短描述（132 字符内）

```
自动记录你在网页间复制的内容：Ctrl+C 即收藏，正则规则自动采集，划词即记录。本地存储，一键合并导出。
```

### 详细描述

```
ClipFlow 是一个跨网页复制内容收集器，让你在多个网页之间复制信息时不再来回切换记事本。

■ 核心能力
· 手动采集：任意网页 Ctrl+C，内容自动进入侧边栏列表，附带来源标题、网址、图标与时间
· 自动采集：创建「URL 条件 + 正则表达式」规则，页面加载、SPA 路由切换、动态渲染出的命中内容无需任何按键即自动入库
· 划词记录：选中文字稳定后自动记录（可在设置中关闭），覆盖浏览器“划词自动复制”场景
· 全文搜索：正文 / 网页标题 / 网址多字段模糊搜索，关键词高亮
· 文档工作台：将多条剪藏组织为文档，拖拽排序、编辑、Markdown 实时预览
· 双模式导出：纯净复制（仅原始内容）或 Markdown 详情复制（含来源）；支持 JSON 备份导入导出
· 批量管理：勾选批量删除、按筛选全部删除

■ 适用人群
技术调研、资料收集、工单处理、价格对比、AI 提示词素材收集……任何需要“从多个页面攒材料”的场景。

■ 隐私承诺
本地优先：所有数据仅保存在浏览器 IndexedDB，无服务器、无遥测、不上传任何内容。
```

### 分类 / 语言

- 分类：生产力工具（Productivity）
- 语言：中文（简体）+ English

## 3. 隐私权规范填写

| 字段 | 内容 |
| --- | --- |
| 单一用途 | 在侧边栏中集中记录、搜索与整理用户在网页间复制及按规则采集的文本内容 |
| `sidePanel` 权限用途 | 扩展的全部用户界面均在侧边栏中呈现 |
| `favicon` 权限用途 | 使用浏览器内置 `_favicon` 服务在列表中显示来源站点图标，不产生额外网络请求 |
| `clipboardWrite` 权限用途 | 用户点击「复制全部 / 详情」时将合并结果写入系统剪贴板 |
| Content Script 用途 | 监听用户主动复制的文本、按用户自建规则扫描页面可见文本；所有处理均在本机完成 |
| 是否收集用户数据 | 否——不传输、不共享、不出售任何数据；无远程代码；无分析统计 |

## 4. 提交与审核

1. 控制台 → 新增项 → 上传 zip
2. 依次完成：商店详情 → 隐私权规范 → 分发设置
3. 提交审核（通常数小时至数天出结果）
4. 被拒时按驳回理由补充权限说明后升版本重新上传
